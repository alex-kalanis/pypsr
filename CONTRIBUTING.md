# Contributing to pypsr

## Reporting issues

When reporting issues please include as much detail as possible about your operating system, pypsr version and python
version. Whenever possible, please also include a brief, self-contained code example that demonstrates the problem.

## Contributing code

Thanks for your interest in contributing code to pypsr!

The author thinks that this package is a whole, but something might be missed and you want to fix it. Then please make a
pull request.

### A note on feature enhancements/API changes

If you want some API changes, then please consider that this package is just port of PHP-FIG within limitations of
Python. For more please begin with PHP-FIG and then after the proposal there is accepted this port will get the feature.
